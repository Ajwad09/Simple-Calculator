# Simple Calculator

A simple and responsive calculator application
developed using HTML, CSS and JavaScript.

## Project Overview

This project is a browser-based calculator
designed to perform basic arithmetic operations.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal Input
- Clear (AC)
- Delete (DEL)
- Division by Zero Error Handling
- Responsive Design

## Project Structure

Simple-Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the calculator buttons.
